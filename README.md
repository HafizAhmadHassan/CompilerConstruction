# Compiler Construction in Java

A collection of Java projects from a **Compiler Construction** course at university.

## Overview

The repository contains several Java projects built as course assignments, including a compiler implementation plus supporting mini-projects. Each folder is a standalone assignment.

## Repository Structure

```
├── compilerAs1/    # Compiler implementation + documentation
├── MYAIRLINE/      # Airline-related course project
└── minesweeper/    # Minesweeper game project
```

## Tech Stack

Java, compiler theory (lexing / parsing), Object-Oriented programming.

## Status

Completed course assignments.
